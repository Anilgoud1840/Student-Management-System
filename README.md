# 🎓 Student Management System

A web-based Student Management System developed using **Python and FastAPI** to manage student records efficiently through CRUD operations.

## 🚀 Features

- **Create:** Add new student records.
- **Read:** View student details.
- **Update:** Edit existing student information.
- **Delete:** Remove student records.
- User-friendly web interface.
- Database connectivity using SQLite.

## 🛠️ Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS
- Jinja2
- Pydantic
- Uvicorn

## 📚 Concepts Learned

- CRUD Operations
- FastAPI Fundamentals
- HTTP Methods
- Backend Development
- Database Connectivity
- Data Validation
- Template Rendering

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Anilgoud1840/Student-Management-System.git
```

### 2. Open the project folder

```bash
cd Student-Management-System
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install fastapi uvicorn jinja2 python-multipart pydantic
```

### 6. Run the application

```bash
uvicorn main:app --reload
```

### 7. Open in your browser

```text
http://127.0.0.1:8000
```

## 🎯 Project Objective

The main objective of this project is to understand and practically implement FastAPI fundamentals by building a real-world student management application.

This project provided hands-on experience with backend development, CRUD operations, database connectivity and integration of different technologies.
